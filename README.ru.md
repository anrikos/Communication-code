# Код общения: Развитие адекватной контекстной реакции (АКР) в среде LLM

[Read in English](README.md)

Инновационная методология на стыке нейробиологии и искусственного интеллекта, разработанная для помощи людям с расстройствами аутистического спектра (РАС) в развитии навыков социальной коммуникации. Проект использует возможности больших языковых моделей (LLM) для перевода изменчивого социального контекста в плоскость рациональных аналитических систем на базе подхода **Social Thinking**.

## 🧠 Суть проблемы
Традиционные методики (ABA, TEACCH, Социальные истории) обучают человека «сверху-вниз», закрепляя жесткие шаблоны поведения. Это приводит к механическим реакциям и невозможности перенести навык при малейшем изменении ситуации.

«Код общения» переворачивает этот подход, используя **аналитическую логику «Снизу-Вверх»**. Метод компенсирует сенсорную запутанность, превращая социальную ситуацию в структурированную задачу с понятным вводом, процессом и управляемым выходом.

## 🚀 Ключевые преимущества метода
* **Модель ILAUGH:** Перевод социальной интуиции на уровень математической логики и причинно-следственных связей.
* **Виртуальная среда LLM:** Использование высокой речевой адаптивности ИИ для преодоления ригидности и эффекта «лабораторных условий».
* **Гладкий перенос навыков:** Высокая сходимость действий ИИ-ассистентов с поведением реальных людей позволяет успешно применять опыт в реальной жизни.

## 🛠️ Программа и модули курса
1. **Модуль 1:** Знакомство с ИИ-собеседником (Снижение тревожности, паттерн «Матрица»).
2. **Модуль 2:** Базовые социальные скрипты (Жесткие алгоритмы).
3. **Модуль 3:** Инициатива и диалог (Развитие гибкости).
4. **Модуль 4:** Работа со сложными ситуациями и отказами.
5. **Модуль 5:** Финальная интеграция (Овладение методом моделирования).

## 🔬 Системный инструментарий
* **Промптинг и векторизация:** Структурирование входных данных для ИИ.
* **Компонентный анализ и дискретизация:** Разбор сложных ситуаций на элементы.
* **Матричный метод и круги Эйлера:** Визуализация логических связей.
* **Скрытые марковские модели:** Прогнозирование последовательностей действий.
